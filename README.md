# *Transactions-analysis*

## Описание:
    1. Проект для анализа банковских транзакций находящийся в EXCEL-файле.
    2. Генерирует JSON-данные для веб-страниц.
    3. Формирует EXСEL-отчёты.

## Где найти:
*Репозиторий с проектом находится по адресу [github.com/AmirGadzhimirzaev/transactions_analysis](https://github.com/AmirGadzhimirzaev/transactions_analysis.git)*

## Что внутри:

### Модули:

1. **[views.py](src/views.py)** - генерирует главный JSON-ответ для веб-страницы "Главная"
2. **[utils.py](src/utils.py)** - функции для реализации веб-страницы "Главная"
